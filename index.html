Things I've built

(3 of them, all live)

  1. 03.1

    Learnloop

    A MERN course platform where instructors create courses and students buy and watch them. It has OTP signup, JWT auth with cookies, Razorpay payments and Cloudinary uploads. I built it while following a MERN course, then redesigned and extended it on my own.

    what I did

    • Traced the full signup flow (OTP email, bcrypt hashing, JWT login) across the React frontend, Express API and MongoDB.
    • Fixed the deployment setup, including the mail, Cloudinary and Razorpay environment variables on Render and locally.
    • Found security bugs in the original project, like password hashes being sent in API responses and a faulty instructor approval check.
    • Redesigned every page, made the course player work on phones, and fixed bugs in the forms, checkout and catalogue API.

    • Razorpay
